A descriptive name for this agent template configuration.

This name is used to identify the template in Jenkins and will appear in logs and the cloud configuration UI. It does not need to match the Proxmox VM name.

Examples:

  • Ubuntu 22.04 Docker
  • Windows Server 2022
  • Build Agent - Java 17

Tip: Use descriptive names that indicate the agent's purpose or capabilities to make it easier to select the right template for your jobs.
