The number of concurrent builds that can run on each agent created from this template.

How to Choose:

  • 1 executor (default): Recommended for most use cases. Each agent runs one build at a time, providing build isolation and predictable resource usage.
  • 2-4 executors: Suitable for lightweight builds on agents with multiple CPU cores. Increases throughput but may cause resource contention.
  • 5+ executors: Only for very specific use cases with very lightweight tasks. Generally not recommended.

Considerations:

  • More executors = more concurrent builds per VM
  • Each executor needs sufficient CPU, memory, and I/O
  • Builds may compete for resources if executor count is too high
  • For heavy builds (compilation, testing), use 1 executor per VM

Recommendation: Start with 1 executor and only increase if you have lightweight builds and want to maximize VM utilization.
