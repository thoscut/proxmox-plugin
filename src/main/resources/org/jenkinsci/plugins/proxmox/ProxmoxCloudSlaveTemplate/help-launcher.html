Launch Method

The launch method determines how Jenkins connects to and starts the agent on the VM after it has been cloned and started by Proxmox.

Recommended launch methods for Proxmox VMs:

  • QEMU Guest Agent Launcher: Best option for Proxmox VMs
    • Uses Proxmox's QEMU Guest Agent to execute commands directly in the VM
    • Doesn't require network connectivity to be fully established
    • Works even if firewall rules aren't configured yet
    • Most reliable for cloud-provisioned VMs
  • Launch agent by connecting to master (JNLP): Good for agents behind firewalls
    • Agent connects outbound to Jenkins
    • Requires agent command to be configured
    • Works well with QEMU Guest Agent Launcher
  • Launch agents via SSH: Traditional method
    • Jenkins connects to agent via SSH
    • Requires SSH credentials configured
    • Requires SSH server running in the VM
    • Requires network connectivity fully established

Best practice: Use QEMU Guest Agent Launcher for Proxmox VMs as it provides the most reliable connection method by leveraging Proxmox's guest agent integration.
