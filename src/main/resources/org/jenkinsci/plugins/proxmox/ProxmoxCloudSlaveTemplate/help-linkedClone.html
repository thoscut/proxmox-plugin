When enabled, creates a linked clone instead of a full clone of the template VM.

Linked Clone vs Full Clone:

Linked Clone (Checked):

  • Faster provisioning: Creates VMs much quicker as only differences are stored
  • Storage efficient: Uses significantly less disk space
  • Dependency: Requires the original template VM to remain available
  • Best for: Development environments, temporary workers, frequent provisioning

Full Clone (Unchecked - Default):

  • Independent: Complete copy that doesn't depend on the template VM
  • More storage: Uses full disk space for each clone
  • Slower provisioning: Takes more time to create
  • Best for: Production environments, long-running agents, maximum reliability

Recommendation: Use linked clones for development and testing where fast provisioning is more important than independence. Use full clones for production where reliability and independence are critical.
