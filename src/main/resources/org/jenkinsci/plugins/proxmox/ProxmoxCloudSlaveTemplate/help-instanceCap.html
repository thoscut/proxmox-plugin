The maximum number of VMs that can be running simultaneously from this specific template.

Purpose: Limits the number of concurrent agents from this template to prevent resource exhaustion and control costs.

How it works:

  • Jenkins will not provision new VMs from this template if this limit is reached
  • This is independent from the global datacenter instance cap
  • The effective limit is the minimum of this value and the datacenter cap
  • Set to 0 for unlimited (limited only by datacenter cap)

Example: If datacenter cap is 20 and this template cap is 5, you can have at most 5 agents from this template, even if the datacenter has capacity for 15 more.

Recommended Values:

  • Lightweight templates: 5-10 VMs
  • Resource-intensive templates: 2-5 VMs
  • Special-purpose templates: 1-3 VMs
