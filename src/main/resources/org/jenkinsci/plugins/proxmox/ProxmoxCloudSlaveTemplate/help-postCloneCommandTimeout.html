Timeout for Post-Clone Command Execution

Maximum time (in seconds) to wait for the post-clone command to complete via the QEMU Guest Agent.

Recommendations:

  • Simple commands: 60-120 seconds (e.g., hostname setup, DNS configuration)
  • Package installations: 300-600 seconds (e.g., apt/yum updates)
  • Complex scripts: 600-3600 seconds (e.g., application deployment)

Important: If the command exceeds the timeout, the provisioning will fail. Set a generous timeout for commands that may take longer to execute.

Default: 300 seconds (5 minutes)
Range: 1-3600 seconds (1 second to 1 hour)
