Optional. The plugin asks the datacenter on which cluster node the template VM currently is, so the template is still found after it was migrated to another node.

Leave this at [Automatic] to choose from the virtual machines of all nodes, or select a node to shorten the list of virtual machines. A selected node is only used if the datacenter does not report where the template VM is, for example because the account lacks the permission VM.Audit for it.

Note: Cloned VMs will be created on the same node as the template VM by default, unless you have configured specific storage or resource allocation rules in Proxmox.
