The Proxmox node where the template VM is located.

This dropdown lists all available nodes in your Proxmox cluster. Select the node that hosts the VM template you want to use for creating agents.

Note: Cloned VMs will be created on the same node as the template VM by default, unless you have configured specific storage or resource allocation rules in Proxmox.

Performance Tip: For better performance, choose nodes with sufficient resources (CPU, RAM, storage) available for creating and running multiple agent VMs.
