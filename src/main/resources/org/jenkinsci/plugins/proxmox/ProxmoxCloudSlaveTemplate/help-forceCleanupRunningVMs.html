Force Cleanup of Running Orphaned VMs

By default, the periodic cleanup task will NOT delete orphaned VMs (VMs without a corresponding Jenkins node) if they are currently running. This is a safety measure to prevent accidental deletion of VMs that might be in use.

Enable this option to allow cleanup of orphaned VMs even when they are running.

When to enable:

  • You have VMs that sometimes get stuck in a running state after Jenkins restarts
  • You want aggressive cleanup of all orphaned VMs regardless of their state
  • Your VMs are ephemeral and it's safe to forcefully delete them

Warning: Use this option with caution! Enabling this will delete running VMs that don't have a Jenkins node, which could cause issues if there are legitimate reasons for VMs to be running without nodes.

How it works: The cleanup task runs hourly and checks for VMs whose name matches this template's pattern but don't have a corresponding Jenkins node. With this option enabled, such VMs will be deleted even if running.
