Command to execute on the VM via QEMU Guest Agent after cloning and before the agent connects to Jenkins.

Requirements:

  • QEMU Guest Agent must be installed and running on the template VM
  • The command runs with the privileges of the guest agent (usually root/SYSTEM)
  • The VM must be started before the command can execute

Common Use Cases:

  • Update hostname or network configuration
  • Run cloud-init or configuration management tools
  • Update system packages
  • Configure VM-specific settings
  • Prepare the environment for Jenkins

Example Commands: 

# Linux - Update packages
apt-get update && apt-get upgrade -y

# Windows - Set computer name
powershell.exe Rename-Computer -NewName "jenkins-agent-$(date +%s)" -Force

# Run a configuration script
/opt/setup-jenkins-agent.sh

Important:

  • The command should complete within the configured timeout
  • For long-running tasks, consider using background processes
  • Test commands manually via Proxmox before using in production
  • Use absolute paths for executables
