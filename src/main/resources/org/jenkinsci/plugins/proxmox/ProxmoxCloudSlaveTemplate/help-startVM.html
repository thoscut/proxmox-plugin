Automatically start the VM after cloning.

Enabled (default): The VM will be started immediately after cloning completes. This is the normal behavior for Jenkins agents.

Disabled: The VM will be cloned but left in a stopped state. Useful for:

  • Pre-provisioning VMs for later use
  • Running post-clone commands before starting
  • Manual VM configuration before first boot
  • Testing clone operations without consuming runtime resources

Note: If you disable this option, you'll need another mechanism to start the VMs, or they won't be able to connect to Jenkins as agents.

Recommendation: Keep this enabled unless you have a specific use case requiring manual VM startup.
