The directory on the agent VM where Jenkins will store files and perform builds.

Platform-Specific Defaults:

  • Linux/Unix: /home/jenkins or /var/lib/jenkins
  • Windows: C:\Jenkins or C:\Users\jenkins

Requirements:

  • The directory must exist or be creatable by the Jenkins agent user
  • The agent user must have read/write permissions
  • Sufficient disk space for builds, workspaces, and artifacts
  • Should be on a fast disk for better build performance

Best Practices:

  • Use a dedicated directory, not the user's home directory
  • Avoid system directories like /tmp (may be cleared on reboot)
  • For Windows, avoid paths with spaces
  • Consider using a separate mount point for build isolation
