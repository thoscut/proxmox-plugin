Space-separated list of labels to assign to agents created from this template.

Purpose: Labels allow you to target specific agents for your Jenkins jobs. Jobs can restrict where they run by specifying label expressions.

Examples:

  • linux docker - For Linux agents with Docker installed
  • windows dotnet - For Windows agents with .NET framework
  • ubuntu-22.04 java-17 maven - Specific OS and tools

Best Practices:

  • Use lowercase for consistency
  • Include OS, language runtimes, and tools
  • Be specific but not overly restrictive
  • Use hyphens within multi-word labels (e.g., ubuntu-22.04)

Note: All agents provisioned from this template will have these labels.
