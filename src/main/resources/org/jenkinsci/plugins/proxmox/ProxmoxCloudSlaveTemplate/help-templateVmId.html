The VM ID of the template VM to use for creating Jenkins agents.

This dropdown shows all VMs on the selected Proxmox node. The template VM should be:

  • Properly configured with the Jenkins agent runtime environment
  • Have a snapshot (recommended) for faster cloning
  • Either marked as a template in Proxmox or left as a regular VM

Template VM Requirements:

  • Java runtime installed (version matching your Jenkins controller)
  • Network configuration (DHCP or cloud-init for static IPs)
  • User account for Jenkins agent connection
  • Any build tools or software needed for your jobs

Tip: Use the "Check Template VM Status" button after selection to verify the template is accessible and properly configured.
