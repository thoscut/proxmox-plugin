The time to wait (in seconds) after starting a VM before attempting to connect the Jenkins agent.

This waiting period allows the VM to:

  • Complete the boot process
  • Start network services
  • Initialize the operating system
  • Be ready to accept agent connections

Recommended Values:

  • Fast Linux VMs with cloud-init: 30-45 seconds
  • Standard Linux VMs: 60-90 seconds (default: 60)
  • Windows VMs: 90-180 seconds
  • VMs with slow storage: 90-120 seconds

Tuning Tips:

  • If agents frequently fail to connect, increase this value
  • If VMs boot faster, decrease to speed up provisioning
  • Monitor your VM boot times to find the optimal value
  • Consider using "Wait for Guest Agent" instead for more reliable detection

Setting this too low will cause connection failures; setting it too high wastes time during provisioning.
