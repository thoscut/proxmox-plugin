The snapshot name to use when cloning VMs from the template.

Benefits of Using Snapshots:

  • Faster VM cloning (especially with linked clones)
  • Consistent state for all cloned agents
  • Easy template updates without affecting running agents

Recommendations:

  • Create a snapshot after fully configuring your template VM
  • Use descriptive snapshot names (e.g., base-snapshot, jenkins-ready)
  • Include VM memory state in the snapshot for faster boot times
  • Update the snapshot when you make changes to the template

Linked Clones: If you enable linked clones, the snapshot is mandatory. Linked clones reference the snapshot's disk images instead of creating full copies, saving storage space and speeding up provisioning.
