Startup Waiting Period

Time (in seconds) to wait after starting the VM before attempting to connect the agent. This allows the VM's operating system and services to fully initialize.

Typical values:

  • Linux VMs: 30-60 seconds
  • Windows VMs: 60-120 seconds
  • VMs with many services: 90-180 seconds

Note: If using QEMU Guest Agent with "Wait for agent ready" enabled, this can be set lower as the plugin will wait for the guest agent to report readiness.

Default: 60 seconds
