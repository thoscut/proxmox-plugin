Snapshot Revert Policy

Determines when the VM should be reverted to the selected snapshot.

Available policies:

  • Never: Don't revert the snapshot automatically
  • Before launch: Revert to snapshot before starting the agent (ensures clean state)
  • After disconnect: Revert to snapshot after the agent disconnects (cleanup)
  • Both: Revert both before launch and after disconnect (maximum isolation)

Recommendation: Use "Before launch" or "Both" for reliable, repeatable builds in clean environments.
