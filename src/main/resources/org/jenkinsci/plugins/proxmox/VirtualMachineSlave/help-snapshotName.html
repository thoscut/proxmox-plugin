Snapshot to Revert To

Select a snapshot to which the VM will be reverted based on the configured revert policy. Snapshots allow you to restore the VM to a clean state after job execution.

When to use snapshots:

  • Clean environment: Ensure each job starts with a pristine VM state
  • Security: Remove any changes made during previous builds
  • Consistency: Eliminate environmental drift between builds

Note: The snapshot must exist on the VM before it can be selected. Create snapshots in Proxmox before configuring the agent.
