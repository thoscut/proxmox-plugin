Secondary Launch Method

The launch method determines how Jenkins connects to this agent after the VM is started. For Proxmox VMs, you typically need to choose a secondary launch method in addition to the primary VirtualMachineLauncher.

Common launch methods:

  • JNLP Agent: The agent connects to Jenkins (good for agents behind firewalls)
  • SSH: Jenkins connects to the agent via SSH (requires SSH credentials configured)
  • QEMU Guest Agent Launcher: Uses Proxmox QEMU Guest Agent to launch the Jenkins agent

Recommendation: For Proxmox VMs, use the QEMU Guest Agent Launcher for the most reliable connection, as it can execute commands directly via the guest agent without requiring network connectivity to be fully established.
