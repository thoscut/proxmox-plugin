Add the --ssl-no-revoke flag to curl commands in the generated agent startup script.

Windows-Specific Option: This flag is primarily for Windows environments where curl may fail when it cannot check SSL certificate revocation lists.

When to Enable:

  • Windows agents experiencing SSL certificate revocation check failures
  • Environments without internet access for revocation list downloads
  • Air-gapped or isolated networks
  • Corporate networks with SSL inspection/proxies

When NOT to Enable:

  • Linux/Unix agents (this flag is Windows-specific)
  • Production environments with proper certificate infrastructure
  • When security compliance requires revocation checking

⚠️ Security Warning: Disabling revocation checks means curl will not verify if SSL certificates have been revoked. This reduces security and should only be used when necessary.

Better Alternative: Instead of disabling revocation checks, configure your network to allow access to certificate revocation lists (CRLs/OCSP), or use an internal certificate authority with proper revocation infrastructure.

Note: This only applies when using the auto-generated agent command. If you provide a custom agent command, you must add this flag manually if needed.
