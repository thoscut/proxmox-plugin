Use Jenkins agent direct connection mode (-direct) instead of the standard URL-based connection (-url).

Direct Connection Mode:

  • Agent connects directly to Jenkins using instance identity
  • More secure - uses cryptographic identity verification
  • Better for cloud environments and modern security practices
  • Recommended for new installations

Standard URL Mode (disabled):

  • Agent connects using Jenkins URL and secret
  • Traditional JNLP connection method
  • Compatible with older Jenkins versions
  • Can use WebSocket for improved reliability

⚠️ Important Compatibility Notes:

  • WebSocket: Direct mode does NOT support WebSocket. These options are mutually exclusive.
  • Jenkins Version: Direct mode requires Jenkins 2.217 or later
  • Firewall: Direct mode may require different firewall rules than URL mode

Recommendation: Use standard URL mode with WebSocket enabled for best compatibility and performance. Only use direct mode if you have specific security requirements or compatibility needs.
