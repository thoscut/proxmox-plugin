Maximum time in seconds to wait for the Jenkins agent to connect back to the Jenkins master after executing the agent command.

This timeout only applies when "Wait for Agent Ready" is enabled. If the agent doesn't connect within this time, a warning will be logged but the launch process will continue.

Recommended values:

  • Fast VMs with SSD storage: 30-60 seconds
  • Standard VMs: 60-120 seconds
  • Slow VMs or heavy workloads: 120-300 seconds
