Enable WebSocket transport for the Jenkins agent connection.

Recommended: Enable this option for better performance and compatibility with modern Jenkins setups.

WebSocket provides more reliable agent connections, especially in environments with firewalls or load balancers. If disabled, the agent will use the traditional TCP-based JNLP protocol.

Note: This setting only applies when using the default agent command. If you specify a custom agent command, you need to manually add or remove the -webSocket flag.
