Command to execute on the virtual machine to start the Jenkins agent. The command will be executed using the QEMU Guest Agent.

Leave empty to use the default command which is automatically generated based on the "Use WebSocket" and "Work Directory" settings.

Available variables:

  • {JENKINS_URL} - Jenkins root URL
  • {COMPUTER_NAME} - Agent/computer name
  • {SECRET} - JNLP secret for this agent
  • {VM_ID} - Proxmox VM ID

Default command format (modern):
java -jar agent.jar -url {JENKINS_URL} -secret {SECRET} -name {COMPUTER_NAME} [-webSocket] [-workDir "path"]

Legacy example for Windows:
cd C:\jenkins && java -jar agent.jar -jnlpUrl {JENKINS_URL}/computer/{COMPUTER_NAME}/jenkins-agent.jnlp -secret {SECRET}

Legacy example for Linux:
cd /opt/jenkins && java -jar agent.jar -jnlpUrl {JENKINS_URL}/computer/{COMPUTER_NAME}/jenkins-agent.jnlp -secret {SECRET}

Note: Make sure the Jenkins agent JAR file and Java are available on the target VM at the specified paths.
