Maximum number of attempts to execute the agent command if it fails.

If the guest agent command execution fails (e.g., due to temporary network issues or VM load), this launcher will retry the command up to the specified number of times with a 5-second delay between attempts.

Recommended values:

  • Stable environments: 2-3 retries
  • Unstable networks or high VM load: 3-5 retries
  • Development/testing: 1-2 retries
