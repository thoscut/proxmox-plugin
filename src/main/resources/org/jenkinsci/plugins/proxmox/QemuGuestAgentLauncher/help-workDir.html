Specify the working directory for the Jenkins agent on the VM.

This directory will be used by the agent to store temporary files, logs, and workspace data. Leave empty to use the agent's default working directory.

Examples:

  • Windows: C:\jenkins\workspace
  • Linux: /var/jenkins/workspace

Note: This setting only applies when using the default agent command. If you specify a custom agent command, you need to manually add the -workDir parameter.
