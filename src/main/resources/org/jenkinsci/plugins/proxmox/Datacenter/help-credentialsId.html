Select the credentials to use for authenticating with the Proxmox VE server.

Required Permissions:

  • VM.Allocate - Create and configure VMs
  • VM.Clone - Clone VMs from templates
  • VM.Config.* - Modify VM configurations
  • VM.PowerMgmt - Start, stop, and reboot VMs
  • Datastore.AllocateSpace - Allocate storage for VMs

The credentials should be a Username with password type. The username will be combined with the realm (e.g., jenkins@pam or api@pve).

Tip: Create a dedicated Jenkins user in Proxmox with only the required permissions for better security.
