The authentication realm to use when connecting to Proxmox VE.

Common Realms:

  • pam - Linux PAM standard authentication (uses /etc/passwd)
  • pve - Proxmox VE authentication server (recommended for API users)

Recommendation: Use pve realm for dedicated API users as it provides better isolation from system accounts. Use pam if you need to authenticate with existing Linux system users.

The realm is combined with the username (e.g., jenkins@pve or root@pam) when authenticating with Proxmox VE.
