Disable SSL certificate verification when connecting to the Proxmox VE server.

When to Enable:

  • Testing with self-signed certificates
  • Development environments
  • Internal networks where certificate validation is not critical

⚠ Security Warning: This option should not be enabled in production environments as it makes the connection vulnerable to man-in-the-middle attacks.

Recommended Approach: Instead of disabling SSL verification, configure your Proxmox VE server with a proper SSL certificate from a trusted Certificate Authority, or add your self-signed certificate to Jenkins' Java trust store.
