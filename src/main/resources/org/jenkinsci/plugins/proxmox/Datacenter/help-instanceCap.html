The maximum number of VMs that can be running simultaneously across all templates in this cloud.

Purpose: Limits resource usage and prevents overloading your Proxmox infrastructure.

How it works:

  • Jenkins will not provision new VMs if this limit is reached
  • This is a global cap across all agent templates in this cloud
  • Individual templates can have their own lower instance caps
  • Set to 0 for unlimited VMs (not recommended)

Recommended Values:

  • Small setups (1-2 nodes): 5-10 VMs
  • Medium setups (3-5 nodes): 10-20 VMs
  • Large setups (6+ nodes): 20-50 VMs

Consider your Proxmox cluster's CPU, memory, and storage capacity when setting this value.
