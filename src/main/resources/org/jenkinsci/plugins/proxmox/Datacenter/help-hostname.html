The hostname or IP address of your Proxmox VE server, optionally with port number.

Examples:

  • proxmox.example.com - Uses default port 8006
  • proxmox.example.com:8006 - Explicit port specification
  • 192.168.1.100 - IP address with default port
  • 192.168.1.100:8007 - IP address with custom port

Note: Do not include protocol (https://) - it will be added automatically.
