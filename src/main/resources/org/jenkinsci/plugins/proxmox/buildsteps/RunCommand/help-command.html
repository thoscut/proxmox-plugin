Command to Execute

The command to execute inside the virtual machine via the QEMU Guest Agent. The command is executed as if typed in a shell on the guest OS.

Requirements:

  • QEMU Guest Agent must be installed and running in the VM
  • The command must be available in the VM's PATH or specified with full path
  • Proper permissions must be set for the guest agent user

Examples:

  • Linux: systemctl restart nginx
  • Linux: /usr/local/bin/deploy.sh --env production
  • Windows: powershell.exe -Command "Restart-Service MyService"
  • Windows: C:\Scripts\update.bat

Note: Multi-line scripts should be written as a single command, or stored as a script file in the VM and executed by path.
