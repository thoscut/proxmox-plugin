Wait for Command Completion

When enabled, the build step will wait for the command to finish executing before proceeding to the next step.

Enabled (default):

  • Build waits for command to complete
  • Command output is captured and displayed in build logs
  • Exit code determines build step success/failure
  • Timeout applies to full command execution

Disabled (fire-and-forget):

  • Command starts and build step immediately succeeds
  • Command runs asynchronously in the background
  • No output captured, no exit code checked
  • Useful for starting long-running services or background tasks

Recommendation: Keep enabled unless you specifically need to start a background process without waiting.
