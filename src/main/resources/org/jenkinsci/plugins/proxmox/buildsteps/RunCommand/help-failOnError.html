Fail Build on Command Error

Determines whether the build should fail if the command returns a non-zero exit code.

Enabled (default):

  • Non-zero exit code → Build step fails
  • Build marked as failed
  • Subsequent steps may be skipped (depending on build configuration)
  • Recommended for critical operations

Disabled:

  • Command errors are logged but don't fail the build
  • Build continues regardless of exit code
  • Useful for optional or non-critical operations
  • Good for cleanup tasks that shouldn't block the build

Note: This option only applies when "Wait for completion" is enabled. If not waiting, the exit code cannot be checked.
