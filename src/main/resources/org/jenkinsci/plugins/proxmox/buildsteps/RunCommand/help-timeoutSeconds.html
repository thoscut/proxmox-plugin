Command Execution Timeout

Maximum time (in seconds) to wait for the command to complete. If the command doesn't finish within this time, the build step will fail.

Recommendations:

  • Quick commands: 30-60 seconds (status checks, simple operations)
  • Service restarts: 60-300 seconds
  • Deployments: 300-600 seconds
  • Long-running tasks: 600-3600 seconds

Note: If "Wait for completion" is disabled, this timeout applies to the initial command submission only, not the full execution.

Default: 300 seconds (5 minutes)
Range: 1-3600 seconds (1 second to 1 hour)
