Maximum time in seconds to wait for the command to complete.

This setting only applies when "Wait for completion" is enabled. If the command takes longer than the specified timeout, the build step will be marked as failed (unless "Fail build on command error" is disabled).

Default: 300 seconds (5 minutes)
Range: 1 to 3600 seconds (1 hour)

Consider the nature of your command when setting the timeout:

  • Quick commands (file operations, service restarts): 30-60 seconds
  • Package installations: 300-600 seconds
  • System updates or compilations: 900-3600 seconds
