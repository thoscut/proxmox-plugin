When enabled, Jenkins will wait for the command to complete before continuing to the next build step.

Enabled (default):

  • Jenkins waits for command completion
  • Command output (stdout/stderr) is displayed in build log
  • Build step fails if command returns non-zero exit code
  • Timeout setting applies

Disabled:

  • Jenkins immediately continues to next build step
  • Command runs in background on the VM
  • No output is captured
  • Build step is considered successful if command starts
  • Timeout setting is ignored

Use "fire-and-forget" mode (disabled) for long-running background tasks or when you don't need to capture output.
