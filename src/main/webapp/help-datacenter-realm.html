The authentication realm for the user account in Proxmox VE.

Common Realms:

  • pve: Default Proxmox VE realm for built-in users
  • pam: Linux PAM authentication (system users)
  • ldap: LDAP directory service
  • ad: Active Directory integration

Default: pve - Use this unless you have configured external authentication. The realm must match how the user was created in Proxmox VE.
