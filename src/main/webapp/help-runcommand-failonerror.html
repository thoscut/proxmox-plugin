Controls whether the Jenkins build should fail when the command execution encounters an error.

Enabled (default):

  • Build fails if guest agent is not available
  • Build fails if command times out (when waiting for completion)
  • Build fails if command returns non-zero exit code
  • Build fails on any connection or API errors

Disabled:

  • Build continues even if command fails
  • Errors are logged but don't stop the build
  • Useful for optional or diagnostic commands
  • Build step is marked as unstable rather than failed

Note: This setting does not affect syntax errors or configuration problems (empty commands, invalid VM IDs, etc.) which will always cause failure.
