The username for authentication with Proxmox VE API.

Format: Use just the username without the realm suffix. The realm is specified separately in the "Realm" field.

Examples:

  • Built-in user: jenkins (with realm "pve")
  • System user: jenkins-user (with realm "pam")
  • LDAP user: jenkins.service (with realm "ldap")

Note: Ensure this user has the necessary permissions for VM operations. Consider creating a dedicated service account for Jenkins integration.
