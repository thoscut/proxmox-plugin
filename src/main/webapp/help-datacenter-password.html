The password for the specified user account in Proxmox VE.

Security Note: The password is stored encrypted in Jenkins and is used to authenticate with the Proxmox API. Ensure the user account has appropriate permissions for VM management operations.

Required Proxmox Permissions:

  • VM.Allocate: Create/clone virtual machines
  • VM.Config: Modify VM configuration
  • VM.Monitor: View VM status and information
  • VM.PowerMgmt: Start/stop/reset virtual machines
  • VM.Snapshot: Create and revert snapshots
