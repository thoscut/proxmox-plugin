Maximum time in seconds to wait for the post-clone command to complete.

If the command takes longer than the specified timeout, it will be considered failed and a warning will be logged. However, the VM will still be created as a Jenkins slave.

Default: 300 seconds (5 minutes)
Range: 1 to 3600 seconds (1 hour)

Recommended timeouts by task type:

  • File operations, directory creation: 30-60 seconds
  • Service management (start/stop/enable): 60-120 seconds
  • Package installation (small packages): 180-300 seconds
  • System updates, large installations: 600-1800 seconds
  • Complex setup scripts: 900-3600 seconds

    • Note: Setting very short timeouts may cause successful operations to be marked as failed. Setting very long timeouts may delay slave provisioning if commands hang.
