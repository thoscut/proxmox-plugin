Optional. The plugin asks the datacenter on which cluster node the virtual machine currently is, so the virtual machine is still found after it was migrated to another node.

Leave this at [Automatic] to choose from the virtual machines of all nodes, or select a node to shorten the list of virtual machines. A selected node is only used if the datacenter does not report where the virtual machine is, for example because the account lacks the permission VM.Audit for it.

The list is loaded from the selected datacenter; if it stays empty, check the credential and the Jenkins log.
