The hostname or IP address of your Proxmox Virtual Environment server.

Format Options:

  • Hostname only: proxmox.company.com (uses default port 8006)
  • Hostname with port: proxmox.company.com:8006
  • IP address: 192.168.1.100 or 192.168.1.100:8006

Note: If no port is specified, the default Proxmox web interface port 8006 will be used. Ensure the Jenkins server can reach this address and port.
