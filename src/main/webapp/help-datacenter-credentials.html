Select the Jenkins credentials to use for authenticating with the Proxmox VE server. The credentials must be of type "Username with password" and contain:

  • Username: The Proxmox VE username (e.g., "root" or "jenkins-user")
  • Password: The corresponding password for the user

To add new credentials, click the "Add" button next to the dropdown and select "Jenkins". Enter your Proxmox VE credentials and give them a meaningful description.

Security Note: Using Jenkins credentials is the recommended way to securely store authentication information. Credentials are encrypted and can be managed centrally through Jenkins.
