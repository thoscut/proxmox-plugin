When enabled, automatically executes a command on each newly cloned VM using the Proxmox guest agent.

This is useful for performing initialization tasks after VM cloning, such as:

  • Setting up SSH keys or certificates
  • Configuring network settings
  • Installing or updating software
  • Running initialization scripts
  • Setting up monitoring agents

Requirements:

  • The VM must be started (enable "Start VM" option)
  • The Proxmox guest agent must be installed and running in the VM
  • The guest agent must be enabled in the VM configuration

Note: If the guest agent is not available or the command fails, the VM will still be created as a Jenkins slave, but a warning will be logged. Post-clone command failures do not prevent slave provisioning.
