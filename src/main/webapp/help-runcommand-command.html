The command to execute on the virtual machine using the Proxmox guest agent.

Requirements:

  • The VM must be running
  • The Proxmox guest agent (qemu-guest-agent) must be installed and running in the VM
  • The guest agent must be enabled in the VM configuration

Examples:

  • ls -la /home - List files in home directory
  • systemctl restart nginx - Restart nginx service
  • echo "Hello from Jenkins" > /tmp/jenkins.txt - Create a file
  • apt-get update && apt-get upgrade -y - Update system packages

Note: Commands are executed with the privileges of the user running the guest agent (typically root on Linux systems). Be careful with destructive operations.
