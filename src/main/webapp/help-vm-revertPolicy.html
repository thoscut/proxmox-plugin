Controls when the virtual machine is reverted to its snapshot state during the build lifecycle.

Available Policies:

  • Before Job: Reverts to snapshot before each Jenkins job starts, ensuring a clean state
  • After Connect: Reverts to snapshot after VM launch and connection is established
  • Manual: No automatic revert - must be triggered manually via build steps

Recommendation: Use "Before Job" for consistent, clean build environments. Use "After Connect" when you need the VM ready immediately but want snapshot reset. Use "Manual" when you need full control over when snapshots are applied.
