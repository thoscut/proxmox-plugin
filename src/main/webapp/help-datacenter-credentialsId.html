The Jenkins credential used to log in to Proxmox. Two kinds are supported:
  • Username with password: the username may include the realm (jenkins@pve); otherwise the Realm field is used.
  • Secret text holding a Proxmox API token in the form user@realm!tokenid=secret (as shown by Proxmox when the token is created). API tokens need no login and are the recommended option.
If no credential is selected, the username and password entered below are used.
