The command to execute on each newly cloned VM after it has been started.

Examples:

  • mkdir -p /opt/jenkins && chown jenkins:jenkins /opt/jenkins - Setup Jenkins directories
  • systemctl enable docker && systemctl start docker - Enable Docker service
  • curl -fsSL https://example.com/setup.sh | bash - Run setup script from URL
  • apt-get update && apt-get install -y git curl - Install packages
  • echo 'export JAVA_HOME=/usr/lib/jvm/java-11' >> /etc/environment - Set environment variables

Multi-line commands: Use && to chain commands or separate with semicolons. For complex setup, consider creating a script file in your VM template and calling it here.

Command execution: Commands run with the privileges of the user running the guest agent (typically root on Linux). Be careful with destructive operations.

Environment: The command runs in the context of the VM, not the Jenkins master. Network access and installed software depend on your VM template configuration.
